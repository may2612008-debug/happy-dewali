# Little Light Club — Diwali Website

A responsive, interactive Diwali celebration website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling, colours and animations
- `script.js` — fireworks, interactive diya, optional generated tones and sharing

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

No build tools or package installation are required. Google Fonts are loaded online; system fallbacks are included.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish your site.

## Interactions
- Click **Celebrate the night** for a double fireworks burst.
- Tap/click anywhere in the background to launch fireworks.
- Use **Light a diya** to toggle its brighter glow.
- Sound is off by default; the sound toggle enables soft tones generated in the browser.
- **Share the good vibes** uses the device share sheet where supported, with a clipboard fallback.

Enjoy, and Happy Diwali!
